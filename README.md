# Дашборд возвратов

Локальный аналитический дашборд возвратов маркетплейса. Приложение читает внешнюю базу DuckDB в режиме `read_only`, поддерживает фильтрацию по периоду, категории и продавцу и показывает девять аналитических элементов:

1. сумму возвратов;
2. долю возвратов в деньгах;
3. количество возвращённых позиций;
4. долю возвратов в штуках;
5. помесячную динамику суммы и денежной доли возвратов;
6. помесячную структуру возвратов по статусам;
7. денежную долю возвратов по категориям;
8. таблицу продавцов;
9. таблицу товаров с порогом не менее 20 позиций за выбранный период.

## Установка

Для Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если рабочее окружение `.venv` уже создано, используйте его и установите недостающие зависимости из `requirements.txt`.

## Подключение внешней базы

База данных не входит в репозиторий. Укажите абсолютный путь к существующему файлу DuckDB в локальном `.env`:

```dotenv
DUCKDB_PATH=C:/absolute/path/to/marketplace.duckdb
DUCKDB_READ_ONLY=true
```

Не копируйте базу в проект и не добавляйте `.env` в Git. Пример без секретов хранится в `.env.example`. Приложение подключает внешний файл через `ATTACH ... (READ_ONLY)` и выполняет агрегаты во временной таблице в памяти.

Проверка подключения и контрольных значений:

```powershell
python scripts/check_connection.py
```

## Запуск

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

После запуска откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Методика показателей

- Позиция — одна строка `prod.order_items`; количество товара берётся из `qty`.
- Возвратами считаются статусы `returned`, `not_redeemed` и `lost`.
- Сумма позиции: `qty × (price_at_purchase − discount_amount)`, при пустой скидке используется ноль.
- Позиции без `price_at_purchase` учитываются в позиционных показателях, но исключаются из денежных сумм и долей.
- Сумма возвратов — сумма стоимости позиций с возвратными статусами.
- Денежная доля возвратов — сумма возвратов, делённая на сумму позиций всех статусов в выбранном срезе.
- Возвращённые позиции — количество строк заказов с возвратными статусами.
- Доля возвратов в штуках — сумма `qty` по возвратным статусам, делённая на сумму `qty` по всем статусам выбранного среза.
- Структура возвратов показывает денежные суммы отдельно для `returned`, `not_redeemed` и `lost`.
- Категория определяется на первом уровне иерархии категорий; продавец берётся из `order_items.seller_id`.
- Таблица товаров группируется по товару и продавцу и включает только группы с 20 и более позициями за выбранный период. Доля позиций равна возвращённым позициям, делённым на все позиции группы.
- Границы периода включительны для пользователя; технически верхняя граница запроса задаётся началом следующего дня.
- При отсутствии знаменателя или известной денежной суммы показатель остаётся `null`, а не подменяется нулём.
